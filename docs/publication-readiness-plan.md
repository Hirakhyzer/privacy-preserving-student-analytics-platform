# Publication Readiness Plan

This plan describes how the **Privacy-Preserving Student Analytics Platform** can evolve from a synthetic research prototype into a stronger academic artifact.

## 1. Possible paper framing

Potential title:

> Privacy-Preserving Student Support Analytics with Synthetic Education Data, Fairness Audits, Access Governance, and Human-Review Safeguards

Core contribution:

- A modular student-support analytics architecture.
- A synthetic-data lab for safe experimentation.
- Transparent privacy and quasi-identifier risk auditing.
- Non-punitive intervention governance.
- Subgroup fairness and access-governance evaluation.
- Reproducible reports and a hash-chained audit ledger.

## 2. Candidate research questions

| ID | Question |
|---|---|
| RQ1 | Can privacy-preserving synthetic analytics identify useful learning-support signals without direct identifiers? |
| RQ2 | Which quasi-identifier groupings create privacy-risk flags in student-support data? |
| RQ3 | How do support-signal rates differ across access, commute, and first-generation proxy groups? |
| RQ4 | Can governance checks reduce unsafe or punitive intervention suggestions? |
| RQ5 | Can access logs and audit ledgers make student-analytics workflows more inspectable? |

## 3. Baselines to report

- No-analytics baseline: support review without model signals.
- Simple transparent scoring baseline.
- Pseudonymized scoring pipeline.
- Fairness-aware review pipeline.
- Access-governed pipeline.

## 4. Evidence expected for a stronger paper

- Synthetic data generation details.
- Sensitivity analysis across seeds and cohort sizes.
- Privacy-risk table by quasi-identifier groups.
- Fairness-gap table by subgroup.
- Intervention-governance rejection examples.
- Access-governance flag examples.
- Reproducibility artifacts and audit-ledger verification.

## 5. Real-world extension boundary

A real educational-data study would require ethical review, institutional authorization, data-protection approval, careful sampling, student notice, educator participation, accessibility review, and a harm-mitigation plan.
