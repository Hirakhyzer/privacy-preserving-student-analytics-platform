# Notebooks

Notebook guidance is intentionally lightweight so the repository remains CI-friendly.

Suggested workflow:

1. Run `python scripts/run_synthetic_student_lab.py`.
2. Load outputs from `outputs/results/` in a notebook.
3. Explore support-need scores, privacy-risk groups, fairness gaps, and access-audit flags.
4. Keep all analysis synthetic unless a formal privacy review approves a real-data workflow.
